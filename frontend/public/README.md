# Public Assets

Place your logo image file here as `logo.png`.

The logo should be:
- Format: PNG, JPG, or SVG
- Filename: `logo.png` (or update the import in login/page.tsx and Header.tsx)
- Recommended size: 200x60px or similar aspect ratio

The application will automatically use the image if it exists, otherwise it will fall back to the text-based logo.
