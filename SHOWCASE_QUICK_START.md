# ⚡ Quick Showcase Start Guide

## 🎯 3-Step Setup (2 minutes)

### Step 1: Start Backend
```bash
cd backend
python -m uvicorn app.main:app --reload --port 8000
```

### Step 2: Start Frontend (New Terminal)
```bash
cd frontend
npm run dev
```

### Step 3: Open & Login
- **URL**: http://localhost:3000
- **Admin Login**: `EMP001` / `admin123`
- **Analyst Login**: `EMP002` / `analyst123`

---

## 🎬 5-Minute Demo Flow

1. **Generate Profiles** (1 min)
   - Profiles → Generate → 200 profiles → "Rural vs Urban"

2. **Run Analysis** (1 min)
   - Bias Analysis → Select dimension → Run Analysis
   - Show initial bias metrics

3. **Submit Feedback** (1 min)
   - Feedback → Select bias → Fill form → Submit
   - **Example Feedback**:
     - Severity: 4-5
     - Root Cause: "Bias against rural applicants detected"
     - Mitigation: "Reduce location-based penalties"

4. **Run Mitigation** ⭐ (1.5 min)
   - Mitigation → Run 5 iterations
   - **Highlight**: Infographic showing before/after improvements

5. **Show Results** (30 sec)
   - Dashboard → Show improved metrics
   - Point out: Gap reduction, parity improvement, fairness score
