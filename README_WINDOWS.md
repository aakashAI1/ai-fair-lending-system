# 🪟 Windows Setup - Quick Reference

## One-Click Setup

1. **Double-click `setup-windows.bat`** (or run in Command Prompt)
2. **Edit `backend\.env`** - Add your Gemini API key
3. **Double-click `start-backend-windows.bat`** - Starts backend
4. **Double-click `start-frontend-windows.bat`** - Starts frontend (new window)
5. **Open http://localhost:3000** in your browser

That's it! 🎉

## What You Need

- **Python 3.11+** - https://www.python.org/downloads/ (check "Add to PATH")
- **Node.js 18+** - https://nodejs.org/ (download LTS version)

## Troubleshooting

**"python is not recognized"**
→ Reinstall Python and check "Add Python to PATH"

**"node is not recognized"**
→ Reinstall Node.js or restart Command Prompt

**Port already in use**
→ Close other applications using ports 8000 or 3000

**Can't connect to backend**
→ Make sure backend is running (check terminal window)
